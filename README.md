# Affluens

Plataforma web SaaS para la gestión de asesorías financieras.

Permite gestionar usuarios con un sistema de roles jerárquicos
y la visualización de estadísticas.

## Tecnologías
- PHP
- HTML5 / CSS3 / JavaScript
- MySQL
